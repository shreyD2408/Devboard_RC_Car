# Devboard_RC_Car

A custom remote-controlled car powered by a ESP32-WROOM development board. Controlled wirelessly by a PlayStation 5 (DualSense) Controller. This custom RC Car integrates motor control, mechanical steering, wireless communication, and embedded programming into one project.

# Overview

The project is an RC Car built using the ESP32 microcontroller that can be controlled by a PS5 DualSense wireless controller, rather than a traditional RC transmitter. Controller input is sent via bluetooth to the ESP32 which sends electrical signals to the car's driver motors, steering servo, headlights, and brake lights.

The vehicle has two N20 geared DC motors for propulsion, an L293D motor driver for controlling the motors and a servo motor that controls the steering mechanism. The control logic is implemented on the ESP32 so the user can control forward/backward, steer, brake and switch lights directly from the controller.

This project was designed to investigate the possibility of connecting software with physical hardware using a microcontroller. It is a combination of fundamental engineering principals such as pulse-width-modulation (PWM) of the motor, H-bridge motor control , servo positioning, Bluetooth communication, and real-time input processing.

It's no dedicated RC receiver, but instead, the signals for controlling the vehicle are generated by the ESP32 and interpreted from the controller.

# Project Goals

The main goal is to build a functional RC car using accessible electronic components and custom Arduino firmware.

The project focuses on:
 - Embedded systems: Using an ESP32 to process inputs and control multiple hardware components.
 - Wireless communication: Connecting a PS5 controller to the car using Bluetooth
 - Motor control: Controlling the direction and speed of DC motors through a motor driver.
 - Mechanical systems: Translating servo rotation into physical steering movement
 - Vehicle lighting: Implementing headlights and brake lights that respond to driver inputs
 - Fail-Safe behavior: Stopping the drive motors and centering the steering when the controller disconnects.

## Features

| Feature | Description |
|---|---|
| Wireless controller | Uses a PS5 DualSense controller through Bluetooth |
| Forward and reverse | Uses the left joystick to control throttle |
| Steering | Uses the right joystick to position the steering servo |
| Motor speed control | Adjusts motor output using PWM |
| Headlights | Toggles the headlights using the Triangle button |
| Braking | Uses the L2 trigger to stop commanded motor output |
| Brake lights | Activates the brake lights when braking or when throttle returns to neutral |
| Input deadzone | Filters small joystick movements to reduce unintended motion |
| Controller disconnect handling | Stops the motors and centers the steering when the controller disconnects |

# How it works:

The car is divided into four main systems: the controller interface, the ESP32 control system, the motor and steering system, and the lighting system.

# Controller Interface

The PS5 DualSense controller gives the driver their input. It connects to the ESP32 via Bluetooth with the BluePad32 Library, with joysticks and buttons.

The firmware is constantly reading the values from the controller. These are the throttle, steering position, braking, and lighting commands requested by the driver.

A joystick deadzone is used for joystick input. A deadzone is a small margin around the neutral position of the joysticks in which moving the joysticks is considered neglectable. This is useful to prevent unwanted movements from small changes in the joystick readings.

## Controller Mapping

| PS5 Controller Input | Function |
|---|---|
| Left joystick up | Drive forward |
| Left joystick down | Drive in reverse |
| Left joystick neutral | Stop commanded propulsion |
| Right joystick left | Steer left |
| Right joystick right | Steer right |
| Triangle button | Toggle headlights |
| L2 trigger | Apply the programmed brake command |
| Controller disconnect | Stop motors and centre steering |

# Power Supply

A 18650 Battery Pack provides power the vehicle. Battery must be charged externally.
